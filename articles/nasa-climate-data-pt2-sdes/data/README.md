# Data Notes

This article uses processed NASA climate data generated in Pt. 1.

- Expected local file: `data/processed/climate_data.csv`
- Upstream source: NASA POWER climate data
- Preparation path:
  1. Run Pt. 1 pipeline to generate/refresh processed climate table.
  2. Use that file as input to `notebooks/Climate_pt2.ipynb`.
